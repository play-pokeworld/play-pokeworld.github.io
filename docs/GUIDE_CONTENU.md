# Guide de contenu — point d’entrée

Le tutoriel complet et vérifié se trouve désormais dans :

- [Créer une région et un gameplay de A à Z](GUIDE_CREATION_REGION_A_Z.md) ;
- [version HTML autonome](GUIDE_CREATION_REGION_A_Z.html) ;
- [kit Auroria et mode d’emploi](examples/auroria/README.md).

Il couvre espèces/formes, capacités/apprentissage, objets/talents, lieux/cartes/rencontres,
PNJ/quêtes, portes derrière quête/combat/arène/objet, boutiques, ligues, région/Pokédex/starters,
puis un gameplay complet avec modèle, système, événement, panneau, sauvegarde, migration et tests.

**Correction importante de l’ancien guide :** une nouvelle région ou un effet inédit ne se crée
pas exclusivement avec les tables de contenu. Des registres, règles d’accès et branchements de code
sont nécessaires. Le tutoriel distingue les mécanismes existants et les extensions à développer.
Il précise aussi la sémantique des titres de ligue et des objectifs TALK de cette version.

Les anciennes livraisons restent des rapports historiques ; leurs limites ne remplacent pas
celles du rapport [1.14.25](PHASE_v1.14.25.md).
