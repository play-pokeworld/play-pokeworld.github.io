# Simulation d'équilibrage — v1.16.11

> Généré par `node tools/sim/balance-sim.mjs`. Chaque combat est **réellement exécuté**
> par `BattleSystem` (dégâts, XP, récompenses, tables de rencontre du jeu). Seules les
> décisions du joueur sont modélisées, et elles sont écrites ci-dessous.

## Modèle de joueur

| Hypothèse | Valeur |
| --- | --- |
| Starter par région | kanto: charmander, johto: cyndaquil, hoenn: torchic |
| Niveau d'entrée de région | 5 (starter régional) |
| On quitte une route | quand le Pokémon a 3 niveaux d'avance sur le plus fort des rencontres |
| Session de farm | 12 victoires maximum, soin complet après une défaite (règle du jeu) |
| Abandon d'une route | après 3 sessions perdues d'affilée (mur) |
